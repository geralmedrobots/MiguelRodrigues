# PharmaRobot project overview

PharmaRobot is a differential-drive autonomous mobile robot (AMR) project built around ROS 2 and C++.

## Repository areas

- `pharmarobot/` contains the ROS 2 workspace and robot packages.
- Joystick input is converted into velocity commands for manual operation and testing.
- Motor-control packages provide the interface between ROS 2 commands and the drive hardware.
- `docs/` contains supporting material related to AMR use and applicable standards.

## Intended use

The repository brings together the software needed to develop, test and operate a mobile robotic platform, including manual control, drive integration and supporting technical documentation.
